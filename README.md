# Expense Report Web

A React webview that displays expense reports generated by the [oh-my-fast-tracker](../oh-my-fast-tracker) Telegram bot. Users receive a link in chat and open it to see charts, detailed tables, and export to Excel.

## Features

- **Vietnamese UI** — all labels, dates, and formatting in Vietnamese
- **Date range title** — "Từ 20/07/2026 đến 27/07/2026"
- **Donut chart** — spending breakdown by category with color palette
- **Transaction table** — date (spent_at), category, note, amount — sorted by spending date
- **Excel export** — download `.xlsx` file with all transactions and totals
- **Dark terminal theme** — CRT-inspired design with jade/amber accents

## Architecture

React + Clean Architecture (same layering as the backend).

```
src/
  domain/
    entities/         WeeklySummary, Transaction, CategorySummary
    ports/            ReportRepository (interface)

  application/
    hooks/            useWeeklyReport (React hook, depends on port)

  infrastructure/
    api/              HttpReportRepository (fetches GET /api/report?token=xxx)

  presentation/
    pages/            ReportPage
    components/
      TotalScreen           total amount + date range
      CategoryDonutChart    doughnut chart by category
      TransactionTable      detailed table sorted by spent_at
      ExportButton          download Excel file
```

## Setup

### Prerequisites

- Node.js 18+
- The oh-my-fast-tracker backend running (provides the API)

### Install & run

```bash
npm install
cp .env.example .env   # set VITE_API_BASE_URL
npm run dev            # starts on http://localhost:5173
```

### Environment variables

| Variable | Description |
|----------|-------------|
| `VITE_API_BASE_URL` | Backend API URL (default: http://localhost:3000) |

### How it works

1. User asks the bot for a report ("báo cáo tuần này")
2. Bot generates a JWT token encoding userId + date range
3. Bot sends a link: `https://your-web.app?token=eyJ...`
4. User opens the link → React app reads token from URL
5. App calls `GET /api/report?token=xxx` on the backend
6. Backend verifies token, queries Supabase by `spent_at` range
7. App renders chart + table + export button
