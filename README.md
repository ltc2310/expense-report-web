# Expense Report Web

A React webview that displays expense reports generated by the [oh-my-fast-tracker](../oh-my-fast-tracker) Telegram bot. Users receive a link in chat and open it to see dashboards with KPIs, charts, tables, and Excel export.

## Features

### Weekly Dashboard (`/`)

- **4 KPI cards** — total spending, transaction count, average per transaction, top category
- **Category donut chart + breakdown list** — percentages and progress bars per category
- **Transaction table** — sorted by date, paginated (10 items + "Xem thêm" button), summary row
- **Summary header** — date range display with export button
- **Excel export** — download `.xlsx` file with all transactions and totals

### Trend Dashboard (`/trend`) — NEW

- **Multi-month spending analysis** — 3 to 12 months of data with month selector
- **4 KPI cards** — total for period, monthly average, highest spending month, lowest spending month
- **Trend line chart** — monthly spending over time (Chart.js Line)
- **Category stacked bar chart** — category breakdown per month (Chart.js stacked Bar)
- **Category trend table** — sorted by absolute change %, shows direction indicators (Tăng/Giảm/Ổn định)
- **Top growing & shrinking categories** — highlights biggest changes
- **Incomplete data warning** — banner when some months have no data
- **Month selector** — dropdown to change analysis period (3–12 months), triggers refetch
- **Excel export** — download trend report as `.xlsx`

### Shared

- **12-column responsive grid** — multi-column on desktop (>=1024px), stacked on mobile
- **Skeleton loading** — placeholder UI while data loads (separate skeletons per dashboard)
- **Accessible** — aria-labels, semantic HTML, 4.5:1 contrast ratio, keyboard-navigable controls
- **Vietnamese UI** — all labels, dates, currency formatting in Vietnamese (VNĐ)
- **Dark terminal theme** — CRT-inspired design with jade/amber accents

## Architecture

React + Clean Architecture (hexagonal ports & adapters pattern).

```
src/
  domain/
    entities/
      WeeklySummary.ts          Weekly report data types
      TrendReport.ts            Trend report types + normalizeByCategory helper
    ports/
      ReportRepository.ts       Weekly report port (interface)
      TrendRepository.ts        Trend report port (interface)

  application/
    hooks/
      useWeeklyReport.ts        Fetches weekly data, manages loading/error/success
      useTrendReport.ts         Fetches trend data, clamps months 3–12, manages state

  infrastructure/
    api/
      HttpReportRepository.ts   GET /api/report?token=xxx
      HttpTrendRepository.ts    GET /api/report/trend?token=xxx&months=N&endMonth=YYYY-MM

  presentation/
    pages/
      DashboardPage.tsx         Weekly executive dashboard
      TrendDashboardPage.tsx    Multi-month trend analysis dashboard
    components/
      KpiCard.tsx               Reusable KPI metric card
      SummaryHeader.tsx         Weekly: title + date range + export
      TrendHeader.tsx           Trend: title + period + children slot
      MonthSelector.tsx         Controlled <select> for 3–12 months
      CategoryDonutChart.tsx    Doughnut chart (weekly)
      BreakdownList.tsx         Category list with % and progress bars
      TransactionTable.tsx      Paginated transaction table
      TrendLineChart.tsx        Line chart — monthly spending over time
      CategoryStackedChart.tsx  Stacked bar — category breakdown per month
      CategoryTrendTable.tsx    Table with direction indicators
      ExportButton.tsx          Weekly Excel download
      TrendExportButton.tsx     Trend Excel download
      SkeletonDashboard.tsx     Weekly loading placeholder
      SkeletonTrendDashboard.tsx Trend loading placeholder
    utils/
      formatters.ts             formatCurrency, formatDateRange
      kpiCalculations.ts        computeKpis, computeCategoryBreakdown
      trendKpiCalculations.ts   computeTrendKpis (total, avg, highest/lowest month)
      trendHelpers.ts           getUniqueCategoriesSortedByTotal, sortCategoryTrendsByAbsChange, classifyDirection

  App.tsx                       Routes: "/" → DashboardPage, "/trend" → TrendDashboardPage
```

## Routing

Simple pathname-based routing (no router library):

| Path | Page | Description |
|------|------|-------------|
| `/` | DashboardPage | Weekly expense report |
| `/trend` | TrendDashboardPage | Multi-month trend analysis |

Both pages read `?token=xxx` from the URL query string.

## Setup

### Prerequisites

- Node.js 18+
- The oh-my-fast-tracker backend running (provides the API)

### Install & run

```bash
npm install
cp .env.example .env   # set VITE_API_BASE_URL
npm run dev            # starts on http://localhost:5173
```

### Environment variables

| Variable | Description |
|----------|-------------|
| `VITE_API_BASE_URL` | Backend API URL (default: http://localhost:3000) |

### How it works

1. User asks the bot for a report (e.g. "báo cáo tuần" or "xu hướng chi tiêu")
2. Bot generates a JWT token encoding userId + date range
3. Bot sends a link: `https://your-web.app?token=eyJ...` or `https://your-web.app/trend?token=eyJ...`
4. User opens the link → React app reads token and pathname from URL
5. App calls the appropriate API endpoint on the backend
6. Backend verifies token, queries data, returns JSON
7. App renders the corresponding dashboard

### API endpoints used

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/report?token=xxx` | GET | Weekly summary (transactions, categories, totals) |
| `/api/report/export?token=xxx` | GET | Download weekly Excel file |
| `/api/report/trend?token=xxx&months=6&endMonth=2026-07` | GET | Trend report (monthly breakdowns, category trends) |
| `/api/report/trend/export?token=xxx&months=6&endMonth=2026-07` | GET | Download trend Excel file |

## Known considerations

- **BE returns `byCategory` as object map** — The backend returns `byCategory` as `Record<string, number>` (e.g. `{"Ăn uống": 1053000}`) rather than an array. The frontend normalizes this via `normalizeByCategory()` in the domain entity layer.
- **`topCategory` format varies** — BE may return `null`, a string, or `{name, amount}` object. The type accommodates all shapes.
- **No client-side router** — Uses `window.location.pathname` for simplicity. If more routes are added, consider adding `react-router-dom`.
