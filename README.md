# Expense Report Web

A React webview that displays expense reports generated by the [oh-my-fast-tracker](../oh-my-fast-tracker) Telegram bot. Users receive a link in chat and open it to see an executive dashboard with KPIs, charts, detailed tables, and export to Excel.

## Features

- **Executive Dashboard** — professional grid layout with KPI cards, charts, and transaction table
- **4 KPI cards** — total spending, transaction count, average per transaction, top category
- **12-column responsive grid** — multi-column on desktop (≥1024px), stacked on mobile
- **Category donut chart + breakdown list** — percentages and progress bars per category
- **Transaction table** — sorted by date, paginated (10 items + "Xem thêm" button), summary row with total
- **Summary header** — date range display with export button
- **Skeleton loading** — placeholder UI while data loads
- **Accessible** — aria-labels, semantic HTML, 4.5:1 contrast ratio
- **Vietnamese UI** — all labels, dates, and formatting in Vietnamese
- **Dark terminal theme** — CRT-inspired design with jade/amber accents
- **Excel export** — download `.xlsx` file with all transactions and totals

## Architecture

React + Clean Architecture (same layering as the backend).

```
src/
  domain/
    entities/         WeeklySummary, Transaction, CategorySummary
    ports/            ReportRepository (interface)

  application/
    hooks/            useWeeklyReport (React hook, depends on port)

  infrastructure/
    api/              HttpReportRepository (fetches GET /api/report?token=xxx)

  presentation/
    pages/
      DashboardPage         executive dashboard (primary)
    components/
      KpiCard               single KPI metric card
      SummaryHeader         title + date range + export action
      CategoryDonutChart    doughnut chart by category
      BreakdownList         category list with % and progress bars
      TransactionTable      paginated table sorted by spent_at
      SkeletonDashboard     loading placeholder grid
      ExportButton          download Excel file
    utils/
      formatters.ts         formatCurrency, formatDateRange
      kpiCalculations.ts    computeKpis, computeCategoryBreakdown

  App.tsx                   renders DashboardPage
```

## Setup

### Prerequisites

- Node.js 18+
- The oh-my-fast-tracker backend running (provides the API)

### Install & run

```bash
npm install
cp .env.example .env   # set VITE_API_BASE_URL
npm run dev            # starts on http://localhost:5173
```

### Environment variables

| Variable | Description |
|----------|-------------|
| `VITE_API_BASE_URL` | Backend API URL (default: http://localhost:3000) |

### How it works

1. User asks the bot for a report ("báo cáo tuần này")
2. Bot generates a JWT token encoding userId + date range
3. Bot sends a link: `https://your-web.app?token=eyJ...`
4. User opens the link → React app reads token from URL
5. App calls `GET /api/report?token=xxx` on the backend
6. Backend verifies token, queries Supabase by `spent_at` range
7. App renders dashboard with KPIs, chart, table, and export button
